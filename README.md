# Evolving Titan Mod

A Fabric mod featuring a 4-stage evolving titan with advanced mechanics.

## Features

- 4-stage evolving titan with exponential growth mechanics
- Advanced tracking systems for the titan
- Specialized player gear for combat and mobility

## Requirements

- Minecraft: Java Edition 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/evolving-titan-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- The titan will spawn naturally in the world.
- Use the specialized gear to track and combat the titan.
- The titan will evolve through 4 stages, each with increasing power and abilities.

The mod does not have a configuration file yet, but it will be added in future updates.
